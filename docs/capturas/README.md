# Capturas

Hechas con la versión web de la app (Expo) y el panel servido por la API, con **datos de demostración**
(eventos, usuaria y entrada inventados). El QR de `app-07-entrada-qr.png` está firmado de verdad con el sistema nuevo
(HMAC), con una clave de prueba.

| Captura | Qué muestra |
|---|---|
| `app-01-bienvenida` | Primera apertura |
| `app-02-inicio-eventos` | Catálogo de eventos |
| `app-03-detalle-evento` | Ficha del evento: fecha, precio en € y elección de asiento |
| `app-04-login` | Inicio de sesión al ir a pagar sin sesión |
| `app-05-perfil` | Perfil (ahora con acceso a «Mis entradas») |
| `app-06-mis-entradas` | Mis entradas con su evento |
| `app-07-entrada-qr` | Entrada con QR firmado |
| `panel-01-login` … `panel-04-usuarios` | Panel de administración |
